# Spring Core Study

스프링 핵심 원리와 객체 지향 설계를 예제 코드와 함께 학습하는 저장소입니다.

## 학습 기록

- [Section 2. 객체 지향 설계와 스프링](docs/section-02-객체지향-설계와-스프링.md) — 다형성, SOLID, IoC와 DI
- Section 3. 스프링 핵심 원리 이해 1: 예제 만들기 — 학습 후 정리 예정

## 현재 예제

회원 가입과 조회 기능을 통해 인터페이스와 구현체의 관계를 살펴봅니다. 회원 저장소는 메모리의 `Map`을 사용합니다.

## 테스트 실행

Java 17을 준비한 뒤 프로젝트 폴더에서 실행합니다.

```powershell
.\gradlew.bat test
```
